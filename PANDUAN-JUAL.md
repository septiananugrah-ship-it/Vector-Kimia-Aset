## 3. Urutan unggah yang disarankan (Adobe Stock)

1. Mulai kecil: 20–30 file terbaik dulu (poster tema gelap, lembar set ikon, beberapa pola).
2. Tunggu hasil review (biasanya beberapa hari). Lihat mana yang diterima/ditolak.
3. Jika diterima, lanjutkan bertahap 50–100 file per minggu.
4. Ikon tunggal yang sangat mirip (mis. 20 atom berbeda nomor) rawan ditolak sebagai "similar content";
   unggah sebagian saja, utamakan lembar set.

### Cara unggah ke Adobe Stock
1. Masuk ke contributor.stock.adobe.com.
2. Unggah file `.eps` dari folder `eps/` (boleh bersama `.jpg` dengan nama sama dalam satu ZIP per aset).
3. Di halaman metadata pilih **Upload CSV** → pilih `adobe_stock.csv` dari ZIP set yang sama.
   Judul, keyword, dan kategori terisi otomatis.
4. Centang **"Created using generative AI tools"** untuk setiap file.
5. Untuk file berisi teks (poster), pastikan tidak menyebut merek/nama orang di judul & keyword.
6. Kirim untuk review.

## 4. Etsy & pasar lokal (printable)

- Jual sebagai **unduhan digital**: PDF/PNG resolusi tinggi. Ekspor dari EPS/SVG ke PDF A4/A3/A2
  (mis. dengan Inkscape atau Illustrator), atau pakai JPG 7000 px untuk poster.
- Paket yang laku: "Chemistry Posters Bundle (10 posters)", "Lab Equipment Flashcards", "Periodic Table
  Printable (dark & light)", "Chemistry Coloring Pages".
- Pasar Indonesia: poster cetak **versi Indonesia** (tabel periodik, model atom, wujud zat, keselamatan lab)
  untuk sekolah, bimbel, dan siswa; file PDF untuk guru di Lynk.id/Karyakarsa.

## 5. Wajib dicek sebelum dijual

- **Angka & istilah di poster** ditulis dari pengetahuan AI dan belum diverifikasi ke sumber resmi.
  Cocokkan dengan buku/IUPAC terutama: massa atom tabel periodik, titik didih alkana, nilai contoh pH,
  trayek indikator, tegangan sel Daniell (1,10 V), dan istilah terjemahan Indonesia.
- Font yang dipakai: **Inter** (lisensi SIL OFL, boleh untuk komersial); teks sudah berupa outline.
- Template sosmed/sertifikat berisi teks contoh (placeholder) yang memang untuk diganti pembeli.
